# Sofa Read 应用标志

2026-11-09。甲骨文「册」的长短竹简和双道编绳作为主图形，字形重新绘制。切尔西蓝向紫色过渡，Team WE 红用于短绳尾。名称 Sofa Read 保留在书库标志旁。

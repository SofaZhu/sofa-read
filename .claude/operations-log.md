# 操作记录

已检查目标 SSH 仓库及同级项目的构建、测试与 React 组件实现。当前环境未提供顺序思考、任务管理、Context7 或 Desktop Commander 工具，改用本地文件、官方源码与官方文档完成检查。电子书和 PDF 复用既有阅读引擎，纯文本只补齐编码识别、目录识别及引擎所需的数据适配。

移动端共用 React 阅读界面，原生层仅负责文档访问、设备电量、息屏、字体与 Android 音量键。未使用复制到应用目录的文件选择方式。检查了异步打开、重新定位和退出的调用链，切书时取消渲染回调并关闭原生文件流，电子书翻页串行执行。

原生依赖下载的 Gradle 分发地址在本机返回 504，改用已缓存的 Gradle 8.13 执行同一构建任务。Electron 运行组件网络下载失败，使用本机缓存的锁定版本执行冒烟测试。

沉浸阅读改版沿读取入口、引擎与原生桥追溯异步清理。正文解析与模块加载并行，封面和 PDF 目录独立完成。跨章视图按可见位置预载，销毁时取消加载和监听，回收前保护当前位置。电子书分页 iframe 的宽度可包含整章多个页面，触点按当前可见区域重新计算。连续滚动合并存储写入，返回和换模式会刷新最后的阅读位置。

阅读细节优化沿手势入口、阅读组件与平台翻页事件检查收起逻辑。搜索扫描与可见批次相互独立，切换查询或关闭面板会取消旧扫描和观察器。书签使用原有书籍定位数据，按当前 PDF 页或电子书正文可见范围显示填色。段落间距从空值回退到原书排版，旧设置可以直接读取。

目录和全文搜索复用全屏页头，列表区独立滚动。全文搜索的分批观察器改用结果区作为滚动根，开始新查询时重置滚动位置。命中片段由 PDF 与电子书引擎标出范围，界面使用蓝色文字显示命中部分。

标志根据用户后续指示改为甲骨文「册」的竹简形态，蓝紫为底，红色只用在一段编绳。检查 512 像素和 32 像素效果，沿用现有书库标志位与各平台图标资源。iOS 图标以不带透明通道的 RGB 位图保存。
